# 表情包联网搜索

**版本：1.0.2 · 作者：yutan123**

让 SkyTide 机器人从[斗了个图](https://www.dogetu.com)搜索表情包，并把选中的图片发到当前聊天。插件无需额外配置、账号或 API Key。

## 安装或更新

1. 下载 `skytide_meme_search-1.0.2.zip`，无需解压。
2. 在 SkyTide 打开「侧边栏 → 插件 → 导入」，选中该 ZIP。已安装此插件时，使用「更新」入口选择新版 ZIP。
3. 启用插件，并确认要使用它的机器人可以调用该插件。如果机器人同时启用了其他表情包搜索插件，可以关闭旧插件，避免选错工具。

## 使用

直接在机器人聊天里用自然语言提出要求，例如：

- 发一张无语表情包。
- 找一张猫猫抱抱的表情包发给我。
- 发一个开心的动图表情包。

插件根据网站图片的标题匹配关键词，不识别图片画面。找不到时，可以把要求缩短成「无语」「抱抱」「猫猫」等词；动图是否播放取决于原图和 SkyTide 的显示方式。

## 常见问题

- **机器人只回了文字，没有图片**：确认插件已启用且机器人有权使用，再明确说「搜索并发到当前聊天」。搜到候选并不等于发送成功。
- **没有匹配结果**：换一个更短的情绪词或角色名。插件不会用普通照片凑结果。
- **提示网站不可用或图片下载失败**：检查网络，或稍后再试。搜索和下载依赖第三方网站，网站故障、页面变化或限制访问都可能影响使用。

## 联网与隐私

插件只连接 `https://www.dogetu.com`，搜索时会把关键词发送给该站，并从该站下载表情图片。插件不读取聊天历史。图片版权归原权利人所有，公开可访问不代表可以商用。
